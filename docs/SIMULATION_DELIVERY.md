# Операционная смена — результат этапа

Основной режим приложения заменён двадцатиминутной 2D-симуляцией рабочей смены.
Схема вагона, шесть зон, пять пересекающихся событий, исследование скрытых фактов,
NPC с памятью, оборудование, служебная связь, станции и отложенные последствия
работают на чистом серверном домене. Прежние сценарии сохранены в «Тренировки».

Состояние, команды и однократные награды хранятся в PostgreSQL. Worker работает
без браузера. Completion DomainEvent даёт XP и положительные учебные gains
регламента/коммуникации; профиль и рейтинг объединяют результаты двух режимов.
Новые достижения и полный black-box разбор сохраняются. Runtime LLM отсутствует.

## Интеграционное восстановление

Промежуточный браузерный прогон создал одну синтетическую смену во время
пересборки. При окончательном уточнении семантики first_reaction_seconds её
snapshot перестал совпадать с replay. Сохранена резервная копия вне Git;
14команд проверены, изменено только производное поле времени реакции под rowlock.
Команды, receipts, ledger и прежние результаты тренировок не удалялись.
Следующий полный прогон и независимый запуск на чистой БД прошли успешно.
