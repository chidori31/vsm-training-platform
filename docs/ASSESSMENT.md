# Наблюдаемая учебная оценка

Методика `demo-methodology-v1` — демонстрационная. Это не утверждённые правила
транспортной компании, не медицинская рекомендация и не допуск сотрудника к работе.
Пороги и последствия требуют проверки профильным методистом до реального обучения.

## Два независимых результата

**XP** — накопленная учебная активность. Рабочая смена может выдать награду один
раз за сохранённое завершение. Новое прохождение — новый результат. Знакомство,
демонстрация, целевая практика и альтернативная попытка XP не начисляют.

**Свидетельства компетенций** — выполненные наблюдаемые критерии разных ситуаций.
Они не вычисляются из XP или места в рейтинге. Повтор ситуации обновляет её
свидетельство. UI показывает число наблюдений и недостаточность данных отдельно.

## Критерии операционного режима

| Компетенция | Наблюдаемое основание |
|---|---|
| Безопасность | Опасные и медицинские обращения взяты под контроль |
| Сервис | По известным обращениям подтверждён результат |
| Проверка и оформление | Факты подтверждены, результат записан |
| Приоритеты | Первое завершённое действие не позднее 60 секунд от сообщения |
| Коммуникация | Завершён разговор, уточняющий потребность участника |

Отсутствие соответствующей ситуации даёт `met: null`. Невыполнение измеримого
критерия — `false`; выполнение — `true`. В разборе сохраняются ID критерия,
версия методики, версия содержания, объяснение и ID событий-доказательств.
Время реакции включает чтение, принятие решения и выполнение действия; это
не измерение физиологической реакции человека.

Графовые сценарии добавляют свидетельства из структурированных изменений
компетенций, сервиса и безопасности. Доступные альтернативы и таймаут входят в
интерпретацию. Нельзя получить высокий результат, отправив score с клиента.

Учебная устойчивость требует минимум трёх разных наблюдаемых ситуаций и
80% выполненных критериев. Эти пороги явно демонстрационные. Автоматические
рекомендации воспроизводимы, используют локальные правила, не обращаются к LLM.

## Воспроизводимость и границы

Опубликованное содержание закреплено в прогоне; история намерений повторно
проверяется движком. Реконструкция и альтернативная попытка используют тот же
snapshot содержания и seed. Просмотр прошлой секунды не меняет время сервера.
Новые правила не применяются задним числом к сохранённым прогонам v1.

Итоги характеризуют действия в ограниченной модели. Повторяющееся затруднение
служит поводом для целевой практики и разговора с инструктором. Оно не является
диагнозом, оценкой личности или основанием для кадрового решения.
